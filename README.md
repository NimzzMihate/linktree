## ✨ Fitur Utama
* **🤖 Claude AI Integration:** Chatbot interaktif via API Claude (NexRay). Ketik `claude [pesan]`.
* **🎵 Spotify-Style Music Player:** Playlist interaktif dengan kontrol penuh.
* **📊 Audio Spectrum:** Visualizer musik yang bergerak dinamis.
* **🕒 Real-time WIB Clock:** Jam digital presisi di header terminal.
* **🌈 RGB Gemini Border:** Efek border profil animasi neon tipis.
* **📟 Interactive CLI:** Terminal yang merespon perintah `help`, `about`, `neofetch`, dll.

## 🛠️ Teknologi

- **Deployment:** Vercel / GitHub Pages
